# Paper 1 Final S01–S16 Authoritative Source Set v1

This directory freezes the final documentary source set that will be
used to construct the Paper 1 supplementary materials.

No biological analysis was performed.

No FASTQ, BAM, SAM, CRAM, VCF or FASTA sequence content was interpreted.

The final selections were made after:

1. high-recall source mapping;
2. automated shortlist curation;
3. editorial classification of final, rules, manifest, terminal,
   repair and failed artifacts; and
4. scientific review of which artifacts are appropriate for
   publication-facing supplementary evidence.

Historical failed or repair artifacts are excluded from the main
scientific supplements unless explicitly assigned to S15, the
reproducibility/provenance ledger.

Files copied into this directory are convenience copies only.

The canonical research artifacts remain in their original Results,
Data or Scripts locations.

SHA256 identity is the authoritative link between each copied source
and its canonical original.

The next step is to render S01–S16 from this frozen source set without
altering any scientific result.
